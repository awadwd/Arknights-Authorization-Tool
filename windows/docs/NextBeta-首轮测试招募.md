> 版本：1.0.0-beta.3（Next Beta）　｜　平台：Windows 10 / 11 · 64 位　｜　形态：桌面客户端（免安装运行时）

## 一、这个工具是干什么的

「方舟通行证谷子查询工具」解决的是一个很具体的问题：**手里这盒谷子/通行证，到底可能是谁。**

- 想按角色查：这个干员出过哪几盒、盒号是多少
- 想按盒号查：这一盒里有哪些角色、概率怎么分布
- 想看成色：某盒的完整收录名单、预测盒号、往期记录

手机端（小程序 / App）已经跑了一年多，覆盖明日方舟与**明日方舟：终末地**两个专区。这次招募的是 **Windows 桌面版**的首轮内测。

### 为什么还要做桌面版

不是因为"手机版不够用"，而是查谷子这件事经常发生在电脑前：

| 场景 | 桌面版怎么解 |
|---|---|
| 一边看群消息/表格，一边查盒号 | 常驻托盘，`Ctrl + Alt + A` 随时唤出，查完关掉不占任务栏 |
| 要同时对照「干员」和「盒号」两头 | 查询页左右双栏同屏，不用来回翻页 |
| 挂着对数据、翻日历看上新 | 窗口位置记忆 + 开机自启，开机就在那儿 |
| 深夜查、嫌白底刺眼 | 液态玻璃主题，浅色 / 深色两套 |

技术上它是 **WinUI 3 外壳 + 内嵌与手机端同一套页面**：业务逻辑不重写，所以数据、功能、更新节奏和手机端保持一致；桌面侧额外做了窗口、导航、托盘、热键这些系统集成。

## 二、这一版（Next Beta）重点变了什么

首轮测试的核心不是"能不能用"，而是**这几块新东西在真实机器上稳不稳**：

1. **终末地专区改成原生桌面页**
   首页与设置页不再是把手机页放大居中，而是按桌面尺寸重做的 WinUI 原生界面。数据要能正常出（不是一排"—"）。

2. **标题栏一键切换工具包**
   明日方舟 ⇄ 终末地，右上角一个按钮直接切，图标和文案跟着变，不用回首页再点。

3. **模拟抽卡 · 联机对战（本轮新增）**
   - 局域网直连：一人建房，另一人填 `IP:端口` 加入，双人同步抽卡、比分实时更新
   - 大厅模式：可自建服务端，支持在线列表、邀请、房主踢人（进阶玩法，见测试任务）
   - 注意：**双方都必须用 Windows 版**，小程序端连不了这类直连地址

4. **桌面布局成体系**
   查询页双栏、日历页「日历 / 时间线」并排、抽卡页「普通 / 对战」并排；窗口拉窄会自动退回切换模式。

5. **修掉了一个会让程序"假死"的问题**
   上一版在部分机器上启动后会一直停在「正在重新加载…」，终末地首页数据全变成「—」。本轮已定位并修复，所以**这一项请重点复测**。

6. 细节：展柜页在桌面端不再弹「加载成功」打扰；联机说明改成页面内可展开的「如何远程联机？」，不再开页就弹窗。

## 四、招募对象与门槛

首轮计划 **〔20〕** 人，宁缺毋滥——人少一点、反馈扎实一点，比凑人数有用。

### 硬性条件（不满足会白测）

1. **系统**：Windows 11，或 Windows 10 1809 及以上，**64 位**
2. **能自己装软件**：安装包免管理员权限，但需要你能处理 Windows 的「已保护你的电脑」提示（未签名程序的正常现象）
3. **愿意给真实反馈**：至少完成 3 项必做任务，按模板回报；不接受"挺好的"这种反馈
4. **能配合复现**：发现问题时，愿意按我们给的步骤再走一遍

### 加分项（有则优先）

- 有 **Windows 10**（1809–22H2）的机器 —— 兼容性最容易出问题，我们特别缺这类样本
- **多显示器 / 非 100% 缩放**（125%、150%、200%）或 4K 屏 —— 版式最容易崩的场景
- 有**两台电脑**（或一台 + 一台虚拟机），能做联机对战测试
- 同时用过手机端，能对比「同一功能两端表现是否一致」
- 熟悉抓日志、会看任务管理器，能描述"点了哪一步、卡多久"

### 明确不适合的

- 只用手机、没有 Windows 电脑的
- 期望这是"成品正式版"、不能接受 Beta 阶段偶发问题的
- 只想要安装包、不打算反馈的（正式版发布时会公开，不用挤这一轮）

## 五、测试任务清单

### 必做（P0，三项都要过）

| # | 任务 | 看什么 |
|---|---|---|
| 1 | 安装 → 卸载 → 重装 | 免管理员是否真生效；卸载后 `%LOCALAPPDATA%\AkPassport` 是否按你的选择保留；重装后收藏/设置是否还在 |
| 2 | 明日方舟主链路：搜干员 → 查盒号 → 看展柜 | 结果是否与手机端一致；双栏对照是否顺手；有没有空白/错位 |
| 3 | 终末地专区：首页 + 设置 | 数据是否正常出（**不能是一排「—」**）；标题栏切回明日方舟是否顺、图标对不对 |

### 选做（P1，按你的条件挑）

4. **联机对战（局域网）**：两台机器各开一个客户端，一人建房一人加入，打满 3 局
5. **大厅模式**（进阶）：跑一遍自建服务端 → 输地址进大厅 → 邀请 → 开一局
6. **长时挂机**：托盘常驻 2 小时以上，再用 `Ctrl + Alt + A` 唤出，看是否还在
7. **显示适配**：在 125% / 150% 缩放、或多显示器拖窗口，看版式是否错乱
8. **开机自启**：设置里打开，重启一次验证

### 不需要测的

- 扫码功能（桌面端没有摄像头调用，明确不支持）
- 桌面小组件（安卓专属，Windows 版没有）
- 手机端 / 小程序（不在本轮范围）

## 六、怎么反馈

统一走 **〔微信群 / QQ 群 / 表单链接：待填〕**，一条问题一条消息，别攒着。

### 反馈模板（照抄填写）

```
【页面】例如：模拟抽卡 → 联机对战
【系统】Windows 11 23H2 / 2560×1440 / 缩放 150%
【操作】1. 点「创建房间」 2. 另一台填地址加入 3. …
【期望】应该看到 …
【实际】实际是 …（卡了多久 / 报了什么错）
【附件】shell.log + 截图
```

### 附件怎么取

- 日志：`%LOCALAPPDATA%\AkPassport\shell.log`（直接把这个文件拖进群里）
- 截图：整个窗口截，不要只截一小块，我要看版式和缩放
- 卡死类问题：**先别急着关**，等 10 秒再截，很多问题是几秒后自愈的

### 隐私说明

所有数据都在你本机（`%LOCALAPPDATA%\AkPassport\`），不上传。`shell.log` 只记录运行信息（加载了哪个页面、请求了哪个数据源、报了什么错），**不含账号、密码、聊天内容**。发之前在记事本里扫一眼也可以。

## 七、已知限制（这些不用报，报了也不算 bug）

1. **安装包没有代码签名**，首次运行 Windows 会拦 → 点「更多信息」→「仍要运行」
2. **扫码页不可用**（桌面端无摄像头调用）
3. **没有桌面小组件**（安卓专属）
4. **工具页仍是手机版式**：居中画布放大，不是原生桌面排版（首页和终末地页才是）
5. **异地联机要走穿透**：双方都得是 Windows 版，且小程序端连不了公网直连地址
6. **联机长空闲可能掉线**：当前没有心跳保活，挂太久可能断，重连即可
7. **数据接口变动需要更新版本**：Beta 阶段上游接口一改，可能需要等我们出新包
8. Windows 10 如果打不开页面（白屏），先装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Win11 自带，Win10 部分机器没有）
