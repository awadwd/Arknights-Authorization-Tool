方舟通行证谷子查询工具 · Windows 版
==========================================

【这是什么】
明日方舟通行证（周边礼盒）查询工具的 Windows 桌面版。
用 WinUI 3 做外壳、内嵌与手机端同一套页面，业务功能与手机版一致，
额外提供桌面布局、托盘、全局快捷键。

【系统要求】
· Windows 11（推荐）或 Windows 10 1809 及以上，64 位
· WebView2 运行时：Windows 11 自带；Windows 10 若打不开页面，
  请到 https://developer.microsoft.com/microsoft-edge/webview2/ 安装「Evergreen Runtime」
· 无需安装 .NET 运行时（已自带）

【怎么装】
A. 安装版（推荐）：双击「方舟通行证谷子查询工具-<版本>-安装程序.exe」
   · 免管理员，默认装到 %LOCALAPPDATA%\Programs\方舟通行证谷子查询工具
   · 安装时可选：桌面快捷方式 / 开始菜单快捷方式 / 开机自启 / 装完立即运行
   · 卸载：Windows「设置 → 应用」里找到本程序点卸载，或运行安装目录下的「卸载.exe」

B. 绿色版：把 AkPassport-Win-<版本>-win-x64.zip 整个解压到任意目录
   ★ 整个文件夹一起解压，AkPassport.Win.exe **不能单独拿出来**：
     旁边的 dll 和 wwwroot 文件夹是运行必需的，少一个就白屏或打不开
   · 不要放在 C:\Program Files 下（权限会有问题）
   · 绿色版不写注册表，删掉文件夹就干净了（快捷方式需自己建）

【怎么用】
1. 双击 AkPassport.Win.exe
   · 首次运行 Windows 可能弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」
2. 关闭窗口默认是最小化到托盘（右下角通知区域），
   托盘图标左键唤出、右键可「显示主窗口 / 退出」
3. Ctrl + Alt + A：任何界面下呼出窗口

【第一次启动会问你几件事】
首次运行会弹一个「欢迎使用」向导，这些选项之后都能在「设置」里改：
· 创建桌面快捷方式（默认开）
· 启动时自动更新数据（默认开，每 24 小时静默检查一次）
· 开机自动启动（默认关）
· 关闭窗口时收进托盘（默认开）
· 全局快捷键 Ctrl + Alt + A（默认开）
开始菜单里的入口（「所有应用」中搜索程序名）由程序自动创建，不询问。

【数据存在哪】
%LOCALAPPDATA%\AkPassport\
  ├─ WebView2\          浏览器数据（收藏、设置、抽卡记录都在这里）
  ├─ preferences.json   桌面偏好（托盘、开机自启、主题）
  ├─ window.json        窗口位置与大小
  └─ shell.log          诊断日志（出问题时发给我）
卸载（安装版）=「设置 → 应用」里卸载，或运行安装目录里的「卸载.exe」；
卸载时会问是否保留上面的 AkPassport 目录 —— 选「是」下次重装数据还在。

【这一版有什么】
· 桌面布局：查询页左右双栏（左查干员、右查盒号），日历页「日历 | 时间线」并排，
  抽卡模拟页「普通 | 对战」并排；窗口变窄自动退回切换模式
· 液态玻璃主题（浅色 / 深色），设置里可切
· 侧边栏导航、窗口位置记忆、关闭到托盘、开机自启、全局快捷键
· 关于我们独立竖屏窗口

【已知限制】
· 扫码页依赖摄像头，桌面端不可用
· 桌面小组件是安卓专属，Windows 版没有
· 部分页面（工具页）仍沿用手机端版式，只是居中放大，不是原生桌面布局
· Beta 阶段数据接口如变动，可能需要更新版本

【反馈】
遇到问题请附上 %LOCALAPPDATA%\AkPassport\shell.log，
并说明：① 哪个页面 ② 点了什么 ③ 期望看到什么、实际看到什么。
