■ 这是什么

查「这盒谷子可能是谁」的桌面工具：按干员查盒号、按盒号查角色、
看收录名单与预测数据。手机端已跑一年多，这次是 Windows 桌面版首轮内测。
覆盖明日方舟 与 明日方舟：终末地 两个专区。

桌面版额外做了：常驻托盘（Ctrl + Alt + A 随时唤出）、查询页左右双栏
同屏对照、窗口位置记忆、开机自启、液态玻璃浅色/深色两套。

■ 这一版重点测什么

1. 终末地专区改成原生桌面页 —— 数据要正常出，不能是一排「—」
2. 标题栏一键切换「明日方舟 ⇄ 终末地」
3. 模拟抽卡 · 联机对战（新）—— 局域网建房加入，双方都要 Windows 版
4. 桌面双栏布局（查询 / 日历 / 抽卡页）
5. 上一版「一直停在正在重新加载…」的问题已修，请重点复测

当前数据：方舟 94 盒号 / 417 干员；终末地 10 盒号（数据版本 1.0.8）

■ 谁能来

必须满足：
· Windows 11，或 Windows 10 1809 及以上，64 位
· 会自己装软件（免管理员；需处理「已保护你的电脑」提示）
· 愿意按模板写反馈，至少完成 3 项必做任务

加分（有则优先）：
· 有 Windows 10 的机器（最缺这类样本）
· 非 100% 缩放 / 4K / 多显示器
· 有两台电脑能做联机测试
· 同时用手机端，能对比两端是否一致

不适合：只用手机的、只想要安装包不打算反馈的。

■ 必做任务（三项）

1. 安装 → 卸载 → 重装：免管理员是否生效、数据是否按选择保留
2. 方舟主链路：搜干员 → 查盒号 → 看展柜，与手机端对照
3. 终末地首页 + 设置：数据正常、切回方舟顺不顺

选做：联机对战 / 大厅模式 / 托盘挂机 2 小时 / 缩放适配 / 开机自启

■ 已知限制（不用报）

· 安装包未签名 → 「更多信息」→「仍要运行」
· 扫码页不可用、没有桌面小组件（安卓专属）
· 工具页仍是手机版式居中放大
· 异地联机要穿透，小程序端连不了公网直连地址
· 联机长空闲可能掉线（暂无心跳），重连即可
